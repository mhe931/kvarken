\chapter{Disclosure of AI-Assisted Work}

\section{Tools, purpose and scope}

I used OpenAI ChatGPT in earlier stages of this thesis for organizing research
material, drafting and restructuring chapters, reviewing academic language and
references, and preparing detailed engineering instructions. I later used GitHub
Copilot in VS Code for substantial assistance with repository inspection, Python
implementation, satellite data acquisition and processing scripts, tests, maps,
scientific cross-checks, CSC cPouta deployment, document preparation, and
manuscript editing \citep{openai-chatgpt,copilot}. The underlying model used by
some Copilot sessions was not independently recorded; I do not identify it by an
unverified model version.

I disclose this assistance because it contributed to both the writing and
implementation. AI-generated descriptions and code were not treated as
empirical observations. The satellite observations, held-out counts, and CSC
execution records are linked to saved data, code, and evidence files. The
observed raster pixels and maps were not generated by an image-synthesis
model. Independent optical proxy labels are not represented as field ground
truth, and the CSC metadata replay is not represented as a second raster
classification experiment.

\section{Representative prompts and affected material}

The principal development instructions requested an end-to-end real-data
demonstration, careful interpretation of SAR backscatter, scientific validation
rather than invented accuracy, and an actual CSC cPouta run. These
requirements informed the implemented workflow and especially Chapters 5
and 6. Subsequent instructions requested independent examination of
source-data provenance, mask purity, optical tile ownership, spatial training
and test separation, error metrics, map presentation and reproducibility.

AI-assisted code review helped identify and correct limitations in native
categorical masks, shared optical tile selection, evaluation block reporting,
source provenance and output checksums. AI tools also assisted with wording
and formatting reviews. The prompts, versioned implementation, review notes,
and relevant measured outputs are recorded in the associated project
history; conversational history alone is not a replacement for the archived
evidence.

\section{Verification and remaining responsibility}

The repository retains tests, original acquisition identifiers, configuration,
checksummed processed windows, source hashes, confusion counts, scientific
figures, and verified CSC execution evidence. The reported comparisons were
computed from the actual retained data. Automated checks establish
internal consistency for the tested inputs, not independent field validation
or operational sea-ice accuracy.

I remain responsible for understanding and checking the methods, data,
code, references, interpretations, and limitations before final submission.
This disclosure is not a claim that every author review or university
approval has already been completed. Neither automated checking nor an AI
review replaces my academic responsibility, the supervisor's assessment, or
the university's required Turnitin process \citep{uwasa-writing}.
