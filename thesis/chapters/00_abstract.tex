\par\medskip\noindent\textbf{Abstract}\par

Earth Observation research depends on more than downloading satellite images. A usable
infrastructure must validate metadata, preserve the origin of observations, control external
requests, support spatial queries, and connect these operations to a scientific application.
University research groups also need reproducible procedures when credentials or computing
resources are unavailable. This thesis designs and
evaluates a hybrid Earth Observation infrastructure in the Kvarken Space Center context.
Here, hybrid means external standards-based data access combined with local persistence,
processing and an offline-safe engineering baseline.

The work follows an engineering design-and-evaluation approach. Provider responses are
validated before transformation into a transport-neutral scene model. The implementation
combines bounded asynchronous ingestion, content-addressed payload storage, append-only
provenance, an embedded spatial catalog, metadata quality filters and a read-only educational
interface. An optional scientific environment adds raster processing without changing the
lightweight metadata runtime.

The practical application examines sea-ice candidate mapping in eastern Kvarken using actual
Sentinel-1 radar observations. An independently acquired Sentinel-2 observation supplies
conservative optical proxy labels for snow-covered ice and dark water. A static land-cover
product supports land exclusion, while native-resolution categorical coverage and a coastal
buffer reduce mixed-cell contamination. A scene-specific linear discriminant uses both radar
polarisations. Spatially separated training and evaluation blocks avoid direct sample overlap.
Outputs include georeferenced maps, quantitative reports and checksummed acquisition records. Actual scene metadata is replayed through the
implemented catalog and provenance path.

The engineering evaluation combines automated failure-oriented tests with a preserved
synthetic benchmark. The scientific application demonstrates a complete local processing path,
but also exposes a substantial limitation: many radar ice candidates disagree with the
selective optical water reference. Ordinary agreement is lower than an always-water baseline,
although balanced agreement detects information about both reference classes. The difference
between acquisition times, incomplete optical coverage, wind-sensitive radar backscatter and
unverified upstream noise treatment prevent interpreting candidate area as validated sea-ice
extent. The experiment therefore provides evidence of application integration and diagnostic
evaluation, not an operational ice-monitoring algorithm.

Execution occurred on the local CPU. CSC cPouta deployment was prepared but could not be
verified because authenticated project access was unavailable. No local measurements are
presented as cloud results. The contribution is an auditable connection between infrastructure
and actual satellite analysis, with explicit scientific and deployment boundaries. Further independent observations, repeated acquisitions and an authenticated CSC run remain
necessary.
